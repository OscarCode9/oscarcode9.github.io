Claude Code y Gemini CLI: fallos permiten que un issue de GitHub llegue a los secretos del flujo de CI

Se descubrieron fallos de seguridad en dos herramientas de programación con inteligencia artificial: Claude Code (de Anthropic) y Gemini CLI (de Google). Estos fallos permiten que un mensaje malicioso escondido en un 'issue' (una especie de publicación o comentario) de GitHub pueda colarse en los sistemas de integración continua (CI, por sus siglas en inglés) que los desarrolladores usan para probar y lanzar su código. Al lograrlo, un atacante podría ejecutar comandos en la máquina del desarrollador o robar claves secretas de acceso a servicios, como las API keys.

¿Qué pasó?

Se descubrieron fallos de seguridad en dos herramientas de programación con inteligencia artificial: Claude Code (de Anthropic) y Gemini CLI (de Google). Estos fallos permiten que un mensaje malicioso escondido en un 'issue' (una especie de publicación o comentario) de GitHub pueda colarse en los sistemas de integración continua (CI, por sus siglas en inglés) que los desarrolladores usan para probar y lanzar su código. Al lograrlo, un atacante podría ejecutar comandos en la máquina del desarrollador o robar claves secretas de acceso a servicios, como las API keys.

¿Por qué importa?

Para una persona común, esto significa que las empresas que usan estas herramientas de IA para programar podrían sufrir filtraciones de datos o ataques a sus sistemas si un atacante publica un issue malicioso en un repositorio público de GitHub. Esto puede afectar desde servicios que usamos a diario (como apps de banca o redes sociales) hasta datos personales que las empresas guardan. En el peor de los casos, un atacante podría robar secretos que le permitan acceder a bases de datos internas y causar daños graves. Para los desarrolladores, la recomendación es actualizar las herramientas y tener cuidado con el contenido externo que procesan.

Impacto en tu día a día

Esta noticia está fechada en agosto de 2026, no en los últimos 7 días. Claude Code y Gemini CLI son asistentes de programación basados en inteligencia artificial que ayudan a los desarrolladores a escribir y revisar código. Los 'issues' de GitHub son espacios públicos donde cualquier persona puede reportar bugs o sugerir cambios. El problema surge porque estas herramientas de IA pueden leer esos issues automáticamente para ayudar a resolverlos, pero si un atacante escribe instrucciones ocultas dentro del texto, la IA puede ser manipulada para ejecutar comandos peligrosos en el sistema de CI. Esto se conoce como 'prompt injection' (inyección de instrucciones) y es un riesgo creciente en la era de la IA generativa.
