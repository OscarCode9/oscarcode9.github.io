Claude Code and Gemini CLI Flaws Let a GitHub Issue Reach CI Workflow Secrets

Security researchers found that Claude Code (Anthropic's coding assistant) and Gemini CLI (Google's) can be manipulated through a simple GitHub issue. If an organization uses these tools in its development automation (CI/CD), an attacker can post hidden instructions in a public issue and trick the AI into running commands on the build server or exposing API keys. Anthropic and Google have released updates and guidance.

What happened?

Security researchers found that Claude Code (Anthropic's coding assistant) and Gemini CLI (Google's) can be manipulated through a simple GitHub issue. If an organization uses these tools in its development automation (CI/CD), an attacker can post hidden instructions in a public issue and trick the AI into running commands on the build server or exposing API keys. Anthropic and Google have released updates and guidance.

Why it matters

The impact is not limited to programmers: almost every digital service is built with tools like these. An attacker who steals an API key or runs commands on a development server can modify software before it reaches users, steal customer data, or spread malware through legitimate updates. The risk can be triggered without directly hacking the repository—an attacker just needs to post a comment on a public issue.

Impact on your daily life

To understand: AI coding assistants use the content of issues and pull requests as context to help. That content is untrusted text—anyone can write it in public repositories. When a CI workflow (a bot that automatically builds and tests code) passes that text to Claude Code or Gemini CLI, the model may treat malicious instructions as legitimate commands. This is called indirect prompt injection. It is like someone leaving a sticky note on a task and the assistant following it without knowing it was written by a stranger.
