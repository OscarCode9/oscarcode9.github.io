Claude Code and Gemini CLI Flaws Let a GitHub Issue Reach CI Workflow Secrets

What happened?

A security researcher found that the AI coding assistants Claude Code and Gemini CLI process GitHub issues without treating them as untrusted data. A specially crafted issue can inject malicious instructions that reach the CI workflow and compromise environment secrets, such as by running commands on the host or stealing API keys.

Why it matters

This matters because development teams rely on these tools for automation and often give them access to tokens and credentials. An attacker only needs someone to open an issue or pull request in a repository to potentially access internal infrastructure. It's a new attack vector in the software supply chain, affecting professionals who use these tools every day.

Impact on your daily life

With the rise of AI agents in coding, more tools are automatically reading issues, comments, and code. Prompt injection attacks exploiting this input have been documented before. What's new here is that the attack reaches CI workflows, where AI tools usually run with elevated permissions and access to secrets. This research adds to warnings about the dangers of blindly trusting user-generated content inside autonomous workspaces.

Sources: support.anthropic.com · cloud.google.com · thehackernews.com
