Primera clase del curso: como estructurar prompts mas utiles para obtener mejores respuestas de una IA. First class of the course: how to structure better prompts to get better answers from AI.

En esta primera clase aterrizamos una idea sencilla: la calidad de la respuesta de una IA depende muchisimo de la claridad con la que le explicas quien debe ser, que informacion tiene, que quieres lograr y en que formato esperas el resultado.

In this first class we land a simple idea: the quality of an AI response depends heavily on how clearly you explain who it should be, what information it has, what you want to achieve, and what format you expect.

Objetivo: aprender una estructura base para mejorar prompts y usarla en un demo donde la IA genera un documento practico a partir de contexto real.

Goal: learn a base structure for better prompts and use it in a demo where AI generates a practical document from real context.

La estructura del promptThe prompt structure

La clase propone cuatro piezas para construir mejores instrucciones. No es una formula rigida, pero si un mapa util para no pedirle cosas vagas al modelo.

The class proposes four pieces for building better instructions. It is not a rigid formula, but it is a useful map to avoid vague requests.

Rol

Define como debe comportarse la IA: especialista tecnico, reclutador, administrador, financiero, mentor o el perfil que necesites.

Define how the AI should behave: technical specialist, recruiter, administrator, finance expert, mentor, or whichever profile you need.

Contexto

Incluye informacion real: documentos, CV, datos, imagenes o detalles del problema para que la respuesta no sea generica.

Include real information: documents, resume, data, images, or problem details so the response is not generic.

Tarea

Explica el resultado concreto que quieres obtener. Mientras mas claro sea el objetivo, mejor puede ejecutar el modelo.

Explain the concrete result you want. The clearer the objective, the better the model can execute.

Formato

Pide la salida final: PDF, documento, tabla, pagina web, checklist, imagen, Markdown o cualquier formato util para tu flujo.

Ask for the final output: PDF, document, table, web page, checklist, image, Markdown, or any useful format for your workflow.

Demo de la claseClass demo

En el demo se usa contexto personal, como un CV, para pedirle a la IA que actue como especialista y genere material de practica para una entrevista tecnica. La diferencia importante es que el modelo no trabaja desde cero: trabaja con informacion concreta.

In the demo, personal context such as a resume is used to ask AI to act as a specialist and generate practice material for a technical interview. The important difference is that the model is not working from zero: it is working with concrete information.

Tambien se explica por que las respuestas gratuitas o sin suficiente contexto suelen sentirse genericas, y como mejorar esa salida dando mejores instrucciones, mejores documentos base y formatos mas especificos.

The class also explains why free or low-context responses often feel generic, and how to improve the output with better instructions, better source documents, and more specific formats.

Idea para practicarPractice idea

Despues de ver el video, intenta escribir un prompt con estas cuatro partes: asigna un rol, pega contexto real, describe la tarea y pide un formato especifico. El salto de calidad se nota rapido.

After watching the video, try writing a prompt with these four parts: assign a role, paste real context, describe the task, and request a specific format. The quality jump becomes visible quickly.
